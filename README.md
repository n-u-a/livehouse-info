# ライブハウス情報

47都道府県、実在会場64件を検索・比較できるライブハウス情報サイトです。会場・公演のお気に入り、会場詳細、公式情報・出典・地図への導線を備えています。

## 技術構成

- Node.js 22.13.0以上
- React 19 / TypeScript 5
- Next.js 16互換ルーティング / Vinext / Vite
- Cloudflare Workers / ChatGPT Sites

## ローカル開発

```bash
npm install
npm run dev
```

開発サーバーの表示URLは起動時の出力を確認してください。

## ビルド・テスト

```bash
npm run build
npm test
```

`npm test` はproduction build後、主要ページの生成結果と、検索・お気に入り・詳細・外部導線に必要な要素を確認します。

## 情報の管理

- `app/lib/venues.json`: 会場ごとに出典URL、確認日、確認対象を記録。
- `app/lib/events.json`: 公式に発表された45公演。自動同期ではなく2026-09-13時点のスナップショット。
- 公式ツアー一覧で全国の会場を発見し、会場のアクセスページを照合。Zepp・CLUB QUATTRO・Spotify O-Groupなどの運営会社の会場案内も参照。
- 未確認の数値はnull、住所は「未確認」。推測の最前列人数・柱情報は掲載しない。
- キャパシティにはスタンディング・最大値などの条件を明記。ドリンク代は公演ごとの条件が優先。
- 出典・確認日は会場詳細に表示。会場詳細から公式会場情報と地図検索へ遷移。

## UX

- 検索と結果を最初の画面に配置。PCは左側の地域フィルター、スマートフォンは地域チップ。
- 全半角・英字大小・ひらがなカタカナを正規化して検索。
- 会場名・都道府県・市区町村、規模、並び順、ページ送り。条件はURLに保存。
- 会場と公演のお気に入りをブラウザに保存。既存公演の保存キーを維持。
- 検索結果への戻り導線はsessionStorageに保存した検索条件を復元。
- 過去公演と開催予定を分け、未掲載を「公演なし」と誤認させない。

## 更新

JSONデータを根拠と照合して編集し、出典と確認日を更新して公開する。自動収集結果をそのまま本番へ反映しない。

## GitHubとSitesの運用

1. GitHubの`main`ブランチをソースコードの正本として変更・レビュー・履歴管理する。
2. `npm install`、`npm test`を実行し、データ件数と主要機能を確認する。
3. 確定した`main`のコミットをChatGPT Workで開き、既存の「ライブハウス情報」Sitesプロジェクトへ反映して公開する。
4. 公開時は既存のSitesプロジェクトIDと公開URLを維持し、新しいプロジェクトを作成しない。

Sitesへ反映するときは、ChatGPT Workでこのリポジトリを参照できる状態にして、次のように依頼します。

```text
GitHubのlivehouse-infoリポジトリのmainブランチを、既存の「ライブハウス情報」Sitesプロジェクトへ反映して公開してください。既存URLとアクセス設定は維持してください。
```

秘密情報はリポジトリへコミットせず、必要になった場合はSitesの環境変数・シークレットで管理します。
